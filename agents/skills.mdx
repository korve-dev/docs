title: "Skills"
description: "Pre-built knowledge packs that teach coding agents how to operate Korve."
---

Skills are markdown knowledge packs (`SKILL.md` files) that compatible agent harnesses load on
demand. They encode the Korve mental model, golden paths, and troubleshooting recipes so your
agent does not have to rediscover them every session.

## Install

```bash
curl -fsSL https://korve.dev/skills.sh | sh
```

Claude is the backward-compatible default. Choose the target harness and scope explicitly when
installing for the open Agent Skills directory or Codex:

```bash
curl -fsSL https://korve.dev/skills.sh | sh -s -- --agent agents --global
curl -fsSL https://korve.dev/skills.sh | sh -s -- --agent codex --global
curl -fsSL https://korve.dev/skills.sh | sh -s -- --agent claude --global
```

The supported values are `--agent agents`, `--agent codex`, and `--agent claude`. Replace
`--global` with `--project` to install into the current repository.

## What's in the box

| Skill                     | What it teaches                                                                                          |
| ------------------------- | -------------------------------------------------------------------------------------------------------- |
| `korve-platform`          | Organizations, projects, runtime classes, optional primitives, billing, and equivalent control surfaces. |
| `korve-quickstart-deploy` | The concise create, connect, deploy, verify, and troubleshoot path.                                      |
| `korve-ship-app`          | The agent execution loop from repository inspection through a production smoke test.                     |
| `korve-mcp-setup`         | Connecting MCP clients and using the `search` and `execute` Code Mode tools safely.                      |
| `korve-cli-setup`         | CLI installation, authentication, configuration precedence, commands, and exit codes.                    |
| `korve-iac`               | TOML, JSON, and YAML manifests with plan, apply, export, drift, and immutability semantics.              |

Skills are versioned with the platform; re-run the installer to update.
The public machine-readable release catalog and file checksums are in the
[skills manifest](https://korve.dev/skills/manifest.json).

The native CLI also embeds three focused offline skills (`korve`, `korve-cli`, and `korve-debug`)
for repository setup. They are distinct from the six broader downloadable skills above. See
[Local agent setup](/agents/local-agent-setup) for the idempotent MCP, `AGENTS.md`, skills, and
environment-file workflow.

## Do I need skills if I have MCP?

No — they're complementary. [MCP](/agents/mcp-setup) gives an agent live,
typed access to the API; skills give it the judgment layer: which runtime
class to pick, what to check before creating resources, how to read a
failed deploy. Use both for best results.
