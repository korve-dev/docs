---
title: "Usage and budgets"
description: "Attribute organization cost to projects and named resources, then cap autonomous spend."
---

The live organization rate card is the only pricing source of truth. Read it with `korve billing
show` or the [Billing API](/api-reference/billing); do not hard-code copied rates.

```bash
korve usage organization
korve usage show --project storefront --granularity day
```

Organization usage groups cost by project and named resource. Project usage groups it by meter and
can return UTC day buckets. Use `since` and `until` for a closed billing window.

A project budget stores a monthly USD cap, alert threshold, and optional hard stop:

```bash
korve budget set --project storefront --cap-usd 50 --alert-at 80 --hard-stop
korve budget show --project storefront
```

Setting replaces the previous budget; omitted options return to defaults. Removing a budget does not
remove usage or resources—it allows spend to continue uncapped. Put hard-stop budgets on projects
operated by unattended agents, and alert before the cap so a human can intervene.

See the [Usage API](/api-reference/usage) and [Budgets API](/api-reference/budgets).
