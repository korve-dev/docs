Korve deploys your full-stack apps to `your-app.korve.app` with Postgres,
object storage, logs, and budgets out of the box — plus a platform agent
that explains and fixes deploy and runtime failures.

## How Korve is built

- **Paid-only, usage-based.** No free tier, no seats. You pay for what you
  run, metered against a public rate card.
- **Agent-native.** The dashboard, the `korve` CLI, and the MCP server all
  speak the same typed API. Anything you can click, an agent can call.
- **Declarative when you want it.** Describe projects, environment, and
  domains in a manifest and apply it — the platform reconciles, and never
  deletes anything you didn't ask it to.

## Runtime classes

Every project picks one of two runtime classes at creation:

| Class | Best for | Billing |
|---|---|---|
| `scale-to-zero` | Most web apps and APIs | Per million requests |
| `always-on` | Long-lived processes, websockets, background work | Per compute-hour |
