Privacy-safe web engagement and runtime traffic analytics for a deployed app.

## analytics.get

Web visitors, page views, bounce rate, custom events, live visitors, and top traffic dimensions, plus request, error, and CPU-time analytics. Collection starts only after the application initializes the browser SDK. Visitor identifiers are site-scoped and reset daily. SDK collection does not store IP addresses, cookies, query strings, fragments, or full referrer URLs. The window defaults to 24 hours.

```text
GET /v1/orgs/{orgId}/projects/{projectId}/analytics
```

- **Auth:** Organization API key (`Authorization: Bearer korve_...`) or dashboard session.
- **Minimum role:** `member`
- **Risk:** `read`

### Example

```bash
curl "https://api.korve.dev/v1/orgs/$ORG_ID/projects/$PROJECT_ID/analytics?since=2026-06-01T12%3A00%3A00Z" \
  -H "Authorization: Bearer korve_..."
```

### Responses

| Status | Description |
| ------ | ----------- |
| `200` | Bucketed traffic series with window totals. |
| `404` | No such project or environment in this organization. |
| `422` | Invalid time, granularity, filter, or limit. The maximum window is 90 days. |
| `502` | Analytics are unavailable — try again. |
