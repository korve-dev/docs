---
title: "Infrastructure as code"
description: "Declare your platform state in a manifest and apply it."
---

Describe your organization's projects, environment, and (soon) domains,
storage, and queues in a versioned manifest:

```yaml
version: 1
organization: acme
projects:
  - name: API Server
    slug: api-server
    runtimeClass: always-on
    git:
      repo: acme/api-server
      ref: main
    env:
      NODE_ENV: production
```

- `plan` shows exactly what would change.
- `apply` creates and updates declared resources — and **never deletes**:
  resources missing from the manifest are reported as orphaned and left
  alone.
- Exported manifests mask secret values; masked values are ignored on
  re-apply.
